# 劉慈欣作品年表

> 劉慈欣，男，漢族，1963年6月23日出生於北京，祖籍河南，山西陽泉人。曾為山西娘子關電廠工程師，現在山西陽泉市文聯工作。80年代起開始創作科幻小說，1999年發表第一篇《鯨歌》，至現在已創作四十多篇/部科幻小說，獲得15次銀河獎，三體英文版獲得科幻雨果獎。劉慈欣是目前公認的中國科幻領軍人物。

_【注】該作品年表的作品只列首次正式發表年份和發表出處。_
