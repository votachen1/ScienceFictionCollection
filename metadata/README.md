# 作品元資訊

小說正文保留在倉庫原有的作者、系列目錄中。此目錄集中維護作者和作品的展示資訊，並透過明確路徑繫結正文；Web 構建只讀取 JSON 和圖片，不批次讀取正文。

維護時先區分三類內容：**小說目錄、期刊目錄、來源與核對記錄**。網站目錄只使用前兩類，來源記錄不生成閱讀頁面。

| 想做什麼 | 從哪裡開始 |
| --- | --- |
| 增補小說、語言或格式版本 | `authors.json` 查作者 → 其 `booksFile` 指向的作品清單 |
| 增補期刊 | `periodicals.json` 查刊物 → 其 `issuesFile` 指向的分期清單 |
| 更換頭像、封面 | `avatars/`、`covers/`，並登記各自的來源記錄 |
| 查版本、收錄或清理經過 | `acquisition/` |
| 查原作年份依據 | `publication-years/` |

```text
metadata/
  authors.json                    作家登錄檔，不包含雜誌社或期刊
  books/                          各作者的小說與版本目錄，檔案名使用可讀作者slug
    liu-cixin.json                 例：劉慈欣
    arthur-c-clarke.json           例：亞瑟·克拉克
  periodicals.json                期刊登錄檔，儲存刊名、出版機構及分期清單位置
  issues/
    science-fiction-world.json    《科幻世界》各期，檔案名使用穩定的可讀刊名
  avatars/                        作者或刊物圖示及來源記錄
  covers/                         封面圖片、匹配清單及來源記錄
  acquisition/                    收錄研究、拆分、清理、相容性及匯入記錄
  publication-years/              年份事實核對與歷史審計記錄
  sync.py                         只根據檔案名、路徑和大小同步目錄
```

作者作品清單統一採用 `books/<作者slug>.json`，期刊分期清單採用 `issues/<刊物slug>.json`；分別由登錄檔的 `booksFile`、`issuesFile` 明確指定位置，不從數字ID推測檔案名。作者專項研究記錄也使用可讀作者slug，例如 `acquisition/arthur-c-clarke.json` 和 `publication-years/isaac-asimov.json`。

ID保留在檔案內容中，用於關聯作者、作品、封面和閱讀進度；顯示名稱與元資訊檔案名不承擔身份標識。元資訊清單此次改名不改變正文路徑、公開閱讀slug或作品ID。

記錄檔案使用小寫英文與連字元，獨立任務按 `<用途或對象>-YYYY-MM-DD.json` 命名；持續維護的作者專題使用作者slug。本說明和作品的 `textSource` 提供來源記錄入口。封面當前命名的適用範圍與改進建議見 [封面維護說明](covers/README.md)。


## 作者

`authors.json` 使用 `schemaVersion: 1`，`authors` 中每條記錄包含：

| 欄位 | 含義 |
| --- | --- |
| `id` | 穩定作者標識，例如 `001`；用於內部關聯、閱讀進度和作品清單檔案名 |
| `slug` | 公開網址標識，例如 `liu-cixin`；全域性唯一，姓名翻譯變化時保持不變 |
| `directory` | 小說倉庫根目錄下的作者目錄，必須與真實路徑完全一致，包含原有空格 |
| `booksFile` | 作者作品清單在 metadata 內的明確路徑，例如 `books/liu-cixin.json`；檔案內容中的 `authorId` 必須與本作者ID一致 |
| `name` | 預設顯示姓名，不包含編號 |
| `names` | 按介面語言標記登記的姓名，如 `zh-CN`、`zh-TW`、`en`、`fr`、`de`、`ru`、`ja`、`ko` |
| `avatar` | 相對於 metadata 目錄的頭像路徑，例如 `avatars/001.webp` |
| `bio` | 可選：按語言儲存的簡短原創介紹，目前有 `zh-CN` 和 `en`；其他介面語言按規則回退 |
| `sources` | 可選：簡介資料來源陣列，每條為 `{ "label": "來源名稱", "url": "https://…" }` |

第一版按已有作者目錄整理了簡體中文、繁體中文和英文姓名。其他語言可繼續人工補充，Web 會優先使用對應名稱；缺少對應名稱時使用英文或預設姓名。

頭像從 Web 倉庫現有圖片集中到此目錄，僅縮小尺寸並轉為 WebP，未重新核查來源。

## 作品

每位作者使用一個 `books/<作者slug>.json`，由 `authors.json` 中的 `booksFile` 繫結；檔案中保留 `schemaVersion: 1`、穩定的 `authorId` 和 `books` 陣列。

| 欄位 | 含義 |
| --- | --- |
| `id` | 穩定作品檔案標識；初次登記後應保留，不隨展示標題修改 |
| `slug` | 全域性唯一的公開網址名稱，允許中文，例如 `三體`、`死者代言人-epub`；修改標題時保持不變 |
| `workId` | 穩定作品標識；同一作品的各語言檔案和不同格式共用該值。不同改寫、刪節版可分別登記，避免誤配 |
| `path` | 相對於該作者 `directory` 的檔案路徑，可包含多層系列目錄 |
| `title` | 展示標題，可人工完善版本、譯本等資訊 |
| `format` | `txt`、`md`、`epub` 或 `pdf` |
| `size` | 檔案位元組數，由同步指令碼透過 stat 獲取 |
| `language` | 正文語言標記，例如 `zh-CN`；不表示已翻譯正文 |
| `series` | 系列分組顯示名稱，可用 `/` 表示層級 |
| `cover` | 封面路徑，例如 `covers/works/liu-cixin/三體/reference-edition.webp；未設定時為 `null` |
| `coverSource` | 可選：封面出處 `{ "label": "Open Library", "url": "https://…" }`，在閱讀頁提供連結 |
| `coverStyle` | 可選：`full`（預設）展示完整封面；`artwork` 為無文字插畫，由頁面疊加書名和本地化作者名 |
| `publication` | 可選：創作日期、初刊日期、當前收錄版本的年份與出處；欄位按已查明事實填寫，未確認日期為 `null`，不把創作年當作發表年 |
| `editionNote` | 可選：稿次、網路整理或節寫版本的說明及尚待確認的資訊 |
| `contentStatus` | 可選：`empty-file` 表示現有檔案為空，書目可保留但不能據此認定已核實正文版本 |
| `textSource` | 可選：使用者提供文字或原刊掃描的來源、PDF頁數、提取與收錄日期、檔案摘要和核對範圍；權利依據另見可選的 `rights` 及來源核查記錄 |
| `rights` | 可選：逐份正文的權利判斷、適用地域、證據連結及核對日期；`public-domain-US-supported`僅表示有證據支援美國公版，不代表全球公版或權利人授權 |
| `chapterTitleCorrections` | 可選：TXT/Markdown 已人工核對的標題邊界陣列，每項為 `{ "prefix": "原始標題和緊鄰正文的行首", "title": "該行開頭實際屬於標題的部分" }`；字元與空格須逐字匹配，title 必須是 prefix 的字首；僅在正文中唯一匹配時生效，不改寫原文 |

完整路徑為 `作者.directory / 作品.path`。網頁使用明確登記的 slug，例如 `/authors/liu-cixin/` 和 `/books/三體/`；內部仍透過穩定 id 關聯。slug 允許中文、字母、數字和分隔用的連字元，不透過目錄名猜測作者姓名或展示標題。

第一版登記 211 個作品檔案，同名作品的不同格式、版本分別保留。6 份作者彙總 Markdown 不計為小說作品；已有空 TXT 記錄保留，但不會進入站點地圖。

## 期刊與分期

`periodicals.json` 使用 `schemaVersion: 1` 和 `periodicals` 陣列。每種刊物登記 `id`、`slug`、`name`、多語言 `names`、`publisher`、正文所在 `directory`、圖示 `avatar`，並固定 `kind: "periodical"`。`issuesFile` 明確指向分期清單，例如 `issues/science-fiction-world.json`。

分期清單使用 `periodicalId` 和 `issues`，不再用 `authorId`、`books` 表示期刊。各期繼續使用穩定的檔案 `id`、`workId`、閱讀 `slug` 和 `path`；`contentType` 固定為 `periodical`，`publication.issueYear`、`publication.issueNumber` 分別使用整數年份和期號。排序讀取這些數值，不解析標題字串，也不把第6期直接推測為6月刊。已知出版月份另在來源資訊中登記。

網站設有獨立“期刊”入口：先按年份從新到舊分組，同一年按期號從小到大排列。整期中的文章保留原作者署名；`publisher` 表示出版機構，不作為全期文章的統一作者。閱讀網址與進度ID在本次分類遷移中保持穩定，舊刊物入口仍可訪問。

## 維護

```bash
python3 metadata/sync.py --check
python3 metadata/sync.py
```

指令碼只掃描檔案名和檔案大小，不讀取小說正文。它會保留已有記錄的 id、slug、標題、封面和自定義欄位；新增檔案根據標題生成初始 slug，同名時附加格式、作者名或序號以區分，之後可以人工編輯。已有 slug 不會因標題修改自動變化；重複或非法 slug 會報錯。新增作者須先在 `authors.json` 註冊。

移動或改名已有檔案時，先修改對應記錄的 `path`，保留原 id 和 slug，再執行同步。刪除的檔案會從同步結果中移除。新增封面請放入 `covers/` 並更新該作品的 `cover`。

《創世紀》的原空檔案已於2026年10月19日補入使用者提供的37頁PDF提取文字，保留原路徑、作品ID和slug。文末2002年4月23日為二稿落款，不替代書目所載2004年12期至2005年1期的連載資訊；原刊逐字比對仍待完成。2026年10月18日追查記錄保留當時“正文未匯入”的歷史狀態，當前收錄情況以 `books/liu-cixin.json` 的 `textSource` 和年份核對記錄為準。

發表年份核對記錄儲存在 `publication-years/<作者slug>.json`；[全庫逐項核對記錄](publication-years/verification.json) 覆蓋所有作品檔案，列出原年份、採用年份、來源、版本口徑和待核原因。中短篇按可核實的初刊年，長篇及文集保留有依據的原文書版年或連載年，並在記錄中說明；不把創作、獲獎或重印年份自動當作初刊年。未確認的題名、作者歸屬或改寫版本不推測年份，保留原檔案名；核對記錄不會替代 `books/` 中的穩定 ID、slug 和正文路徑。

[全庫年份缺失檢查](publication-years/audit.json) 記錄各作者的作品檔案數、檔案名年份覆蓋情況及無法確認的條目；年份事實核對結論見上述逐項記錄。作者彙總 Markdown 單獨列為參考資料。

[2026年10月18日追查記錄](publication-years/follow-up-2026-10-18.json) 複核上一輪8項疑點，優先使用儲存的原帖、作者落款、作者授權年表和早期版本原文。《中國2185》的1989明確為創作年，《燒火工》的2012明確為網路首發年；凡爾納《2889年一個美國新聞界鉅子的一天》按正文特徵標為1910年修訂版，並分別記錄1889年首刊和1891年法文修訂。未刊稿和網路整理本的創作年份透過作品 `publication.yearBasis` 與正式發表年份區分，不據此虛構初刊日期。

封面按 `covers/works/<作者slug>/<作品名稱slug>/<版本>.webp` 整理，期刊封面按 `covers/journals/<刊物slug>/<年份>/issue-<期號>-<版本>.webp` 整理。來源編號與圖片摘要保留在清單中。沒有實際封面的作品由閱讀器即時繪製替代圖；舊的未引用示例WebP、SVG及配套生成指令碼已清理。網頁引用圖片統一為metadata內的WebP，頭像最長邊160畫素，封面不超過600×900畫素。

Web 專案執行 `pnpm metadata:prepare` 或重新啟動、構建後，會同步 metadata 與引用圖片。列表和靜態構建不需要正文件案；讀者開啟某本書的閱讀頁時，瀏覽器自動從內容倉庫載入這一本正文，無需再次點選；目錄和構建不會載入正文。新增正文須先推送到小說倉庫，原始檔案連結才可訪問。

作者簡介是根據各記錄 `sources` 中的作者官網、出版社頁面或作協資料重新撰寫的簡短摘要，不復制整段原文。中文介面優先顯示中文簡介，其他語言預設顯示英文；可繼續補充對應翻譯。

## 出版封面整理

`covers/catalog.json` 按穩定作品 ID 記錄全部作品的封面檢索結果，包括來源連結、ISBN（如可用）、原圖摘要和核對狀態。`embedded-cover` 來自對應 EPUB 的封面圖片，只讀取容器目錄、OPF 元資訊和圖片，不讀取章節；`reference-cover` 是已核對作者與作品的參考版本封面，不能據此認定與 TXT 的譯本、版次相同。未核實的記錄繼續使用生成式封面，不把合集或改編版封面直接標成獨立短篇的封面。

`covers/title-aliases.json` 只用於資料檢索，記錄已知作品的原文名稱，不會替換頁面的中文標題。出版封面只壓縮尺寸並轉為 WebP，原圖摘要與壓縮後摘要均記錄；圖片下方仍顯示 metadata 中的書名和本地化作者名。逐條出處同時儲存在作品 `coverSource` 中。來源記錄不代表出版社封面獲得了開放許可，也不與程式碼許可證混為一談。

## 多語言正文版本

介面語言、作者姓名翻譯和小說正文語言分別維護。真正的英文小說檔案必須登記 `language: "en"`（或 `en-US` 等），不能只把中文件案改成英文語言標記。翻譯版本使用自己的 `id`、`slug`、`path` 和 `language`，並用相同的 `workId` 繫結同一作品。`workId` 是穩定內部標識，不隨書名翻譯、網址或路徑改變；新檔案同步時預設將自己的 id 作為 workId，人工關聯翻譯時再修改 workId。

每個作品按“當前介面語言 → 英文 → 任一存在的其他語言”選擇版本；多個其他語言並存時按 metadata 順序選擇一個。目錄按 workId 合併展示同一作品，預設優先 TXT/Markdown，避免不同格式重複佔據書架。每本書的下方及閱讀頁保留版本選擇控制元件，可手動切換語言、格式；選擇按介面語言和 workId 記在本機。同一語言的 TXT、EPUB 等格式都可保留，預設優先線上可讀的 TXT/Markdown，不把格式差異當作不同語言。簡體與繁體中文分別選擇。閱讀頁遇到可用的另一語言版本時進入該檔案自己的網址，閱讀進度始終按具體檔案 id 儲存；沒有翻譯時只回退讀取真實存在的檔案，不自動翻譯正文。

EPUB 線上閱讀與 TXT/Markdown 一樣，僅在讀者開啟該檔案時載入正文；構建不解析 EPUB 章節。當前《火星紀事》EPUB 的 `language` 已按 OPF 與實際章節核對為 `zh-TW`，其餘檔案的語言仍按各自記錄維護。
